
# Healthcare Readmission Prediction

This project focuses on predicting **30-day hospital readmissions for diabetes patients** using machine learning techniques. The analysis is based on the **Diabetes 130-US Hospitals dataset (1999–2008)** containing over **100,000 patient records**.

The goal of this project is to help healthcare providers identify **high-risk patients at discharge** so that preventive care and follow-up interventions can be implemented. By predicting readmissions early, hospitals can improve patient outcomes and reduce unnecessary healthcare costs.

The project includes a complete **end-to-end data science pipeline**, including data preprocessing, exploratory data analysis, feature engineering, model training, and evaluation.

Several machine learning models were tested, with **Random Forest** achieving the best performance. The model achieved around **75% accuracy** with an **ROC-AUC score of 0.65**, demonstrating reasonable predictive capability.

Key risk factors identified include **previous inpatient admissions, emergency department visits, age, and diagnosis category**. The model helps stratify patients into **low, medium, high, and very high risk groups**.

This system can support hospitals in **targeting care management programs**, improving discharge planning, and reducing costly readmissions.

Technologies used in this project include **Python, Pandas, Scikit-learn, Matplotlib, and Seaborn**.
